SECTION 01 · 개요

Step 3 가 추가한 것: 방향성 로코모션 + Debug

Step 2 는 "Gait + Aim" 으로 이동 속도 상태 와 그에 따른 Idle/Cycle 전환을 구현했다. Step 3 는 그 Cycle 을 방향(Forward/Backward/Right/Left) 으로 갈라, 이동 각도를 4 방향으로 판정하고 방향별 시퀀스를 골라 재생한다. 함께 화면 디버그 도구도 들어왔다. 이 문서는 그 작업 결과물을 Monolith MCP 실측으로 분석하고 Step 2 와 비교한다.

★
실측 - Monolith MCP 응답 기준 본 Step 3 문서의 자산 이름·함수 시그니처·변수·그래프 노드·핀 기본값·인터페이스는 모두 project_query.get_asset_details / get_stats, blueprint_query.get_blueprint_info / get_variables / get_functions / get_interfaces / list_graphs / get_graph_summary / get_node_details, animation_query.get_abp_info / get_abp_variables / get_abp_linked_assets / get_state_machines / get_transitions 의 실제 응답을 1 차 자료로 작성했다. 핵심 식별자는 2 개 이상 액션으로 cross-check 했다 (예: S_DirectionalAnims 의 필드 GUID 가 OnCycleUpdate 의 Select 핀 연결과 정확히 일치). 에디터에서만 보이는 항목은 본문에서 "(에디터 확인)" 으로 표기한다.

한 문장 요약

매 프레임 워커 스레드에서 속도와 회전으로 이동 각도를 구하고, CalculateLocomotionDirection 이 그 각도를 히스테리시스(DeadZone) 와 함께 4 방향 중 하나로 굳혀 LocomotionDirection 에 쓰면, ABP_Layers.OnCycleUpdate 의 2 단 중첩 Select 가 (Gait 로 Walk/Jog 묶음 선택 → Direction 으로 F/B/R/L 시퀀스 선택) S_DirectionalAnims 에서 사이클 애님을 골라 부드럽게 갈아끼운다.
