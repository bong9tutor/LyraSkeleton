Step 4 Start / Stop / Pivot
+ Distance Matching + Warping

Step 3 의 "4방향 Cycle" 위에, 이동의 시작(Start) / 정지(Stop) / 방향전환(Pivot) 을 LocomotionSM 의 정식 상태로 추가했다. 세 상태는 Distance Matching 으로 발 미끄러짐을 잡고, 레이어마다 Orientation / Stride Warping 으로 적은 애님으로 임의 방향·보폭을 메운다. 좌우 기울임용 BS_Lean 은 에셋·데이터·합성 노드까지 준비됐지만 Output 연결이 빠진 미완 상태다. 본문은 Monolith MCP 분석과 저자가 BP 에 직접 단 코멘트를 바탕으로 한다.
