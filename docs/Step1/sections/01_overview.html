LyraSkeleton 프로젝트 개요

엔진 버전, 모듈 구성, 빌드 타겟, 현재 구현 상태(BP 중심), 그리고 자산의 위치를 한 장으로 정리한다. 본 문서 전체의 시작점이며, 이후 섹션들은 여기 등장한 자산을 더 깊이 본다.

프로젝트 정체성

LyraSkeleton 은 UE 5.7 기반 프로젝트로, Epic 의 Lyra 와 ALS(Advanced Locomotion System) 에서 보이는 "베이스 포즈 + 무기 상태별 레이어" 구조의 캐릭터 골격을 담고 있다. 현재는 거의 모든 게임플레이가 Blueprint 로 구현되어 있고, C++ 모듈은 진입점만 존재한다.

프로젝트 정체

항목값비고
엔진 버전UE 5.7LyraSkeleton.uproject 의 EngineAssociation 으로 고정
모듈 이름LyraSkeleton (Runtime)게임 코드가 들어갈 단일 모듈
빌드 타겟LyraSkeletonTarget, LyraSkeletonEditorTarget게임 + 에디터, 두 개뿐
기본 맵Content/ALS/Maps/L_Start.umapGameMode, 캐릭터 스폰을 검증하는 진입점
GameModeBP_LsGameMode (Blueprint)현재는 BP 로 구성, 추후 C++ 로 이식 후보
캐릭터BP_LsCharacter (Blueprint)입력·무기 전환·애님 상태가 모이는 곳
입력 시스템Enhanced InputBuild.cs 가 EnhancedInput 모듈을 Public 의존으로 선언

구현 상태

현재 BP 중심
BP_LsCharacter 가 입력·이동·무기 상태·AnimBP 통신을 모두 들고 있다. ABP_Base 의 LinkedAnimLayer 슬롯이 ABP_Pistol/ABP_UnArmed 를 무기 상태별로 갈아 끼운다. C++ 모듈은 IMPLEMENT_PRIMARY_GAME_MODULE 한 줄.
이식 방향 BP → C++
입력 처리·무기 상태 모델·AnimInstance 갱신을 단계적으로 C++(ALsCharacter, ULsAnimInstance, ULsWeaponComponent 등) 로 옮기고 BP 는 데이터/바인딩만 남긴다. 상세 우선순위는 섹션 10.

문서 구성 영역

빌드 환경

UE 5.7 명령 시퀀스. 솔루션 재생성, 에디터 빌드, 패키징.

섹션 02

렌더링 Config

DX12 + SM6, Lumen, Substrate, Ray Tracing, VSM.

섹션 03

C++ 모듈

5 개 파일의 책임. 모듈 의존성, IWYU/PCH 정책.

섹션 04 · 08

자산 게임플레이

Content/ALS 자산 13 개. AnimBP 레이어 체인, Enhanced Input 흐름.
